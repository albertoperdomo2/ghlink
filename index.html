🔗 ghlink

a command-line tool to generate GitHub links for your repository files directly from your terminal

installation

to install ghlink you can follow the steps in the usage guide but basically can be installed using pip 

pip install git+https://github.com/albertoperdomo2/ghlink.git

setup

you can quickly set up ghlink with the new init command:

ghlink init --token YOUR_GITHUB_TOKEN

this creates a configuration file at ~/.config/ghlink/config with your settings

features

  • generate GitHub links for files in a Git repository
  • support for linking to specific lines or line ranges
  • create permalinks using commit SHA instead of branch name
  • support for multiple git remotes (useful for forks)
  • automatically open links in your browser
  • configuration system with defaults for your workflow
  • command-line interface so you never have to leave your terminal
  • feature requests are more than welcomed by filling an issue

    (but the idea is to keep it as simple as possible)
